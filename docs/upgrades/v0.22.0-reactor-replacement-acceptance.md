## Evidence limits and separate decisions

The final source comparison checks 1,619 production Go/protobuf/module files
against the frozen mining fixture with no differences; the candidate binary hash
above is unchanged. The local native batch exited successfully and restored the
existing Docker node. The acceptance audit is reproducible with
`python3 -B build/reactor-replacement/verify-full-lifecycle-acceptance.py build/reactor-replacement/full-lifecycle-85wkyiac`.
This completes the replacement's planned local implementation and verification;
it does not publish or approve a production release.

The saved testnet database is production-shaped testnet evidence, not a fresh
mainnet certification. Its pre-existing empty-address bank row holds 90,000,000
ualpha. The strict bank verifier rejects that source anomaly; a separate audit
proves the row is unchanged and reconciles all remaining balances/events without
weakening the verifier. Per-owner base/bonus reporting covers 31 nonzero-capacity
owners; none earns a new diversity bonus in that snapshot. Positive-bonus cases
are established by the separate synthetic native and real-app fixtures.

The old native upgrade checkpoint crossed unbonding maturity between capture and
replay. Its exact pending-entry and vesting comparisons remain recorded as failed;
the fresh focused fixture closes those comparison gates. It is not relabeled as
a full legacy gameplay population run.

Two cap-driver attempts remain failed evidence: one expired its 180-second wait
before block 1,000, and one reached jail but could not parse an omitted zero-power
RPC field. The successful fresh fixture uses a 600-second wait and an adapter
that normalizes only valid omitted zeros. Unit tests still reject missing
positive contributions through accounting mismatch; export parsing remains strict.

The ICA policy question was resolved on September 24: the user confirmed ICA is
unused, and hosting is disabled with an empty allow-list in the upgrade and fresh
genesis defaults. See the [policy and verification scope](v0.22.0-ica-policy.md).
The historical cap test verifies staking hooks independently of this restriction;
it does not certify gameplay through ICA.

The 2,048-row owner inventory limits remain. These changes add current derived
portfolio state and bounded retry metadata, not financial or efficiency history.
No release was published, remote chain changed, or indexer deployment performed.
